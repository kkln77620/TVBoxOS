# TVBox OS

基于 TVBox 深度定制的安卓电视影视聚合播放器，专为电视 / 盒子场景重新设计：全新六大板块导航、多配置地址管理、聚合搜索、直播触屏控制台、离线缓存下载、视频壁纸与自动更新。

## ✨ 主要特性

- **六大板块导航**：主页 / 分类 / 搜索 / 收藏 / 历史 / 缓存 / 设置，左侧栏一键直达
- **多配置地址管理**：可同时启用多个数据源配置，数据源按配置分组展示，主页配置一键切换
- **聚合搜索**：多源搜索结果按「名称 + 年份」智能合并为同一视频位，详情页可跨源切换；支持拼音首字母相关性排序（输入 `wzzs` → 无职转生置顶）
- **直播触屏控制台**：点击画面呼出控制台（上一台 / 频道列表 / 下一台），3 秒自动隐藏
- **离线缓存下载**：视频详情页一键缓存，缓存管理页实时显示下载进度，支持本地播放 / 删除
- **视频壁纸**：内置多张高清横屏壁纸循环切换，支持上传自定义图片
- **多页滑动设置**：主页 / 播放 / 系统三页设置，底部圆点指示器随滑动丝滑过渡，左侧菜单同步高亮
- **自动更新**：基于 GitHub Releases API，每次启动自动检测新版本，发现更新即弹窗提示

## 📱 使用说明

1. 安装 APK 后进入设置 → 配置地址 → 配置管理，添加或导入数据源地址
2. 可启用多个配置并指定主页配置，主页数据源按配置分组切换
3. 搜索支持拼音首字母 / 中文关键词，聚合结果自动合并多源
4. 直播界面点击画面呼出切换控制台
5. 详情页点击「缓存」离线下载，主页左侧「缓存」查看任务

## 🔄 更新机制

- App 每次启动自动调用 GitHub Releases API（`/repos/{owner}/{repo}/releases/latest`）检查版本
- 新版本发布方式：在仓库 Releases 页面创建 Release（tag 名称即版本号，如 `1.0.20260805_1500`），上传 APK 附件
- 检测到 tag 版本号高于当前版本时，弹出更新对话框（版本名 / 更新说明），可一键下载并安装
- 设置 → 关于 → 「检测更新」可手动检查

## 🔧 构建

```bash
# 环境: Android SDK + JDK 17
./gradlew :app:assembleArm64GenericNormalDebug
```

产物路径：`app/build/outputs/apk/arm64GenericNormal/debug/`
