# TVBox OS

基于 TVBox 深度定制的安卓电视影视聚合播放器，专为电视 / 盒子场景重新设计：七大板块导航、多配置地址管理、内置地址一键导入、聚合搜索、直播触屏控制台、离线缓存下载、视频壁纸与自动更新。

## ✨ 主要特性

- **七大板块导航**：主页 / 分类 / 搜索 / 收藏 / 历史 / 缓存 / 设置，左侧栏一键直达
- **多配置地址管理**：内置 3 个常用配置地址一键导入、缺一补一；可同时启用多个配置，数据源按配置分组展示，主页配置一键切换
- **首次使用手册**：首次启动自动弹出使用教程，引导配置数据源地址
- **聚合搜索**：多源搜索结果按「名称 + 年份」智能合并为同一视频位，详情页可跨源切换；支持拼音首字母相关性排序，输入 `wzzs` 直达无职转生
- **直播触屏控制台**：点击画面呼出控制台，上一台 / 频道列表 / 下一台，3 秒自动隐藏
- **离线缓存下载**：详情页缓存弹窗支持选画质/线路/集数批量入队（缓存默认关闭，需在播放设置中确认警告后启用）；直链与 m3u8 分片合并兼容 AES-128，缓存页分组管理（缩略图/状态/占用），支持暂停 / 继续 / 重试 / 清空 / 本地播放 / 删除
- **视频壁纸**：内置多张高清横屏壁纸循环切换，支持上传自定义图片
- **多页滑动设置**：主页 / 播放 / 系统三页设置，底部圆点指示器随滑动丝滑过渡，左侧菜单同步高亮
- **自动更新**：基于 GitHub Releases API，每次启动自动检测新版本，更新弹窗支持 **GitHub 下载 / 迅雷下载** 双通道

## 📱 使用说明

1. 首次启动弹出使用手册；也可进入 设置 → 配置地址 → 配置管理 查看
2. 配置管理页点「使用内置配置地址」一键导入内置源，或「＋新增配置」手动添加
3. 可启用多个配置并指定主页配置，点配置项「主页源」，主页数据源按配置分组切换
4. 搜索支持拼音首字母 / 中文关键词，聚合结果自动合并多源
5. 直播界面点击画面呼出切换控制台
6. 详情页点击「缓存」离线下载，主页左侧「缓存」查看任务

## 🔄 更新机制

- App 每次启动自动调用 GitHub Releases API `/repos/{owner}/{repo}/releases/latest` 检查版本
- 新版本发布方式：在仓库 Releases 页面创建 Release，tag 名称即版本号，如 `1.0.20260805_1500`，上传 APK 附件
- 检测到 tag 版本号高于当前版本时，弹出更新对话框，含版本名 / 更新说明 / GitHub下载 / 迅雷下载
- 设置 → 关于 → 「检测更新」可手动检查

## 🔧 构建

```bash
# 环境: Android SDK + JDK 17
./gradlew :app:assembleArm64GenericNormalDebug
```

产物路径：`app/build/outputs/apk/arm64GenericNormal/debug/`
